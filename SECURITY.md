# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue.

1. Go to the repo's [**Security** tab](https://github.com/asterysk/Orca-Flightdeck/security).
2. Click **Report a vulnerability**.
3. Say what the problem is, how to reproduce it, and what it could let someone do.

You'll get a reply within a few days. Once it's fixed, a release goes out and the advisory is published, with credit to you if you want it.

## Supported versions

Only the latest release gets security fixes. Flightdeck is in public beta.

## What counts

Things like: a way for a web page or another user to reach the deck helper's local link, keys that run commands without `allow-shell`, or text reaching an agent without a key press.
